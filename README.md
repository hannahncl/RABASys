# RABASys

Rabas Travel & Tours Management System

RABASys is a web-based management system designed to help
Rabas Travel & Tours manage tour packages, bookings,
car rentals, payments, notifications, and reports.

## Technologies Used

- React.js
- Node.js
- Express.js
- MySQL

## Local Development

Run these commands from the repository root:

```sh
npm run install:all
```

Start the frontend and backend in separate terminals:

```sh
npm run dev
```

```sh
npm run backend:dev
```

The backend requires its environment variables to be configured in
`backend/.env` (see `backend/.env.example`).
